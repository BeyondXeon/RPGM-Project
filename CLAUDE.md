- **Language**: JavaScript (ES6+; MZ runs modern Chromium/NW.js)
- **Runtime**: NW.js (desktop deploy), browser-capable web export
- **Code authority**: rpgm-engine-coding skill — alias-never-overwrite, IIFE wrap, PluginManager.registerCommand, save-safe Game_System init
